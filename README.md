# NeuroVista – UI/UX Design Concept

NeuroVista is a futuristic UI/UX design concept focused on neuroscience education and brain exploration. This project showcases a modern user experience built with a dark interface, Liquid Glass aesthetics, and contemporary Apple-inspired design principles.

## Project Includes

- Desktop Website UI
- Mobile Website UI
- iPhone 17 Pro Max Mockup
- Apple Watch Ultra UI
- Interactive Brain Anatomy Concept
- Research & Learning Interface
- Glassmorphism / Liquid Glass Components

## Design Goals

- Create a clean and immersive neuroscience experience.
- Explore Apple's modern visual design principles.
- Build a scalable cross-device interface.
- Demonstrate UI/UX, visual design, and product presentation skills.
